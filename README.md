# Tradesmen Job Alerts – Signup Page

This is a simple GitHub Pages site that lets tradesmen sign up for job alerts.

## How it works

- Tradesmen enter their phone number and trade.
- The site sends their details to a Base44 backend function.
- The backend sends an SMS confirming signup.
- You can then send job alerts to them anytime.
